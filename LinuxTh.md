### Регулярные выражения:
 sudo apt-get install

#### Позиция в строке (якоря)
`^` — начало строки. Выражение ^Linux найдет строки, которые начинаются со слова Linux.  
`$` — конец строки. Выражение done$ найдет строки, которые заканчиваются на done.  
`^$` — пустая строка (символ начала сразу переходит в символ конца).  

#### Поиск символов
`.`(точка) — один любой символ (буква, цифра, пробел).  
`[abc]` — любой один символ из указанных в скобках (или a, или b, или c).  
`[a-z]` — любая строчная буква от a до z (диапазон).  
`[0-9]` — любая одна цифра.  
`[^0-9]` — любой символ, кроме цифры (знак ^ внутри квадратных скобок
означает отрицание).  

### Количество повторений (квантификаторы)
`*` — ноль или более повторений предыдущего символа.  
`+` — одно или более повторений (доступно в ERE).  
`?` — ноль или одно повторение (предыдущий символ либо есть, либо его нет).  
`{n}` — ровно n повторений символа.  

### Стандартные команды:

`uptime` — показывает как долго система работает;  
`uname -a` — информация о ОС;  
`lscpu` — данные о процессоре;  
`ls -l \ -la \ -la -R / \` — показывает имена файлов и директорий. Флаг -l дает более развернутую информацию содержимом текущей директории, а -la дополнительно показывает скрытые элементы. -R / просматривает все элементы на всех дисках, к которым linux имеет доступ;  
`echo $PATH` — показывает пути к директориям из которых linux берет команды (при желании можно создавать новые директории и авторские команды);  
`echo "*text*"` — вывод текста в терминал (кавычки опцианальны);  
`sudo` — super user do, выполнение от имени администратора;  
`wget *webadress*` — скачать файл по адресу;  
`sudo apt-get install *packname*` — скачать пакет;  
`sudo apt-get remove *packname*` — удалить пакет;  
`cat /etc/apt/sources.list` — лист репозиториев, откуда Linux берёт пакеты;  
sudo dpkg -i *packname*.deb — распаковать пакет .deb;  
sudo dpkg -r *packname*.deb — удалить пакет .deb;  
### Работа с файлами и директориями, информация и навигация:

`man` — доступ к системным справочным страницам;  
`info` — чтение Info документации;  
`whatis` — однострочное описания чего-либо;  
`whereis` — найти файлы исполняемого кода, исходного кода и справочной страницы для команды;  
`locate` — быстрый поиск файлов по имени;  
`find` — поиск файлов в иерархии директорий;  
`cd` — смена директории (cd без указания пути переключит в домашнюю директорию (~));  
`cd /` — перейти в корневую директорию;  
`cd ..` — перейти на директорию выше (можно записать ../../.. и тд);  
`pwd` — путь к текущей директории;  
`tree` — выводит дерево иерархии директорий и файлов;

`cat` — вывод содержимого файла;  
`more` — открывает вьюер для просмотра содержимого файла;  
`less` — открывает вьюер для просмотра содержимого файла с возможностью поиска отдельных слов;  
`stat` — показывает развернутые метаданные о файле или директории;  
`file` — показывает **реальный тип** файла (расширения в linux носят лишь рекомендательный характер);  
`sort` — выводит содержимое файла в отсортированном по символам виде (флаг -n отсортирует по номерам);  
`cut` — используется для «вырезания» колонок или частей текста из каждой строки файла или потока данных.  
Флаги `-d` и `-f` работают в паре:
- **`-d` (delimiter / разделитель):** Указывает символ, который разделяет колонки в тексте (по умолчанию это знак табуляции).
- **`-f` (fields / поля):** Указывает номера колонок (полей), которые нужно извлечь;

`grep` — используется для поиска строк, которые соответствуют заданному шаблону (тексту или регулярному выражению), в файлах или потоке данных;  
`uniq` — дедупликация и подсчёт повторов (лучше использовать совместно с `sort`, тк работает с повторяющимися строками);  
`wc` — показывает сколько строк/слов/символов/байт в файле;  
`touch` — создать файл (обновить время элемента если применить команду на существующий файл или директорию);  
`cp *filename* *dirpath*` — копирование файла. В конце можно указать имя копии;  
`cp filename*.* *dirpath*` — копирование всех файлов, в имени которого содержится filename;  
`rm` — удалить файл;  
`mv` — переместить файл или директорию или изменить имя;  
`mkdir` (*exsistdir*/*newdir*)(-p *newdir1*/*newdir2*) — создать директорию;  
`rmdir` — стереть пустую директорию;  
`rm -R *dirname*` — рекурсивно стирает всё содержимое указанной директории;  
`cp -R *outdir* *indir*` — копирование всей директории из одной в другую;  
`sudo rm -R / --no-preserve-root` — **дабл эй волки хатят падвигаца**;  
`ln -s` — создать линк на файл/директорию;  
`ln *originame* *copyname*` — создать точную связанную с оригиналом копию;  

### Потоковые текстовые редакторы:

#### sed

-  `sed 's/*replaced*/*replacement*' *filename*` — замена вхождений заменяемого слова на заменяющее. В конце строки в кавычках можно прописать флаги:
    -  `1/2/3/...` — замена каждого 1/2/3/... вхождения;
    -  `g` — замена всех вхождений;
    -  `w *filename*` — записать результат в файл;
    По умолчанию (без флагов) команда обработает каждое первое вхождение;
-  `sed -f *commandfile* *filename*` — позволяет применить на файл команды, прописанные в другом файле;
-  `sed -e ` — позволяет сделать несколько конструкций замен через `;`;
-  `sed 's!/bin/bash!/bin/csh!' passwd` — позволяет прописывать конструкции в которых фигурирует слэш как шаблоны. В данном случае разделителем выступает `!` (взаимозаменяемо с `+`);
-  `sed '*1/2/3/...*s/*replaced*/*replacement*'` — замена только в стоке под указанным номером. Можно прописать несколько номеров через `,`;
-  `sed '*1/2/3/...*,$s/*replaced*/*replacement*'` — замена во всех строках, начиная с указанного номера;
-  `sed -n '/*template*/s+*replaced*+*replacement*+p'` — совершает замены в строках, подходящих по указанному шаблону. Подавляет вывод за счет `-n` и выводит только те строки, в которых замена прошла успешно (за счёт флага`p`);
-  `sed '*1/2/3/...*$d'` — позволяет удалить все строки, начиная с указанного номера и до конца файла;
-  `sed '/*template*/d'` — удалит все строки, содержащие шаблон;
-  `sed '/*template1*/,/*template2*/d'` — удалит все строки, начиная с той что содержит первый шаблон, заканчивая той что содержит второй;
-  `sed '*1/2/3/...*i\*text*'` — позволяет вставить текст перед указанной строкой;
- `sed '*1/2/3/...*a\*text*'` — позволяет вставить текст после указанной строки;
-  `sed '*1/2/3/...*c\*text*'` — замена текста указанной строки на введенный;
-  `sed '/*template*/c\*text*'` — замена всех строк с шаблоном на введенный текст;
-  `sed 'y/45/89/'` — замена указанных в шаблоне символов по всему файлу на другие **соответственно**. В нашем случае каждая `4` будет заменена на `8`, а каждая `5` на `9`;
-  `sed '='` — выведет все строки с нумерацией;
-  `sed -n '/*template*/='` — вывод номеров строк, в которых содержится указанный шаблон;
-  `sed 'r *file1*' file2` — добавит текст из первого файла после каждой строки второго файла;
-  `sed 'r *file1*' file2` — добавит текст из первого файла после строки под указанным номером второго файла;
-  `sed '/*template*/ {`
	  `r *file1*`
	  `d}' *file2*` — удалит все строки из второго файла, содержащие шаблон, и заменит на содержимое первого файла;
-  `sed -i.bak /*template*/s/*replaced*/*replacement*/' *filename*` — выполнит замены в строках, соответствующих шаблону, и запишет изменения в существующий файл, при этом создав копию предыдущей версии файла с расширением `.bak`;
#### awk

-  `awk '{ print "*text*"}' + anykey` — вывод текста в терминал. Текст выводится не сразу, тк `awk` ожидает поступления данных из потока `stdin`, необходимо предоставить ему эти данный путём ввода любого текста;
-  `CTRL + d` — выход из `awk`;
-  `awk '{print $*1/2/3/...*}' *filename*` — выпишет из файла каждое первую/вторую/третью позиционную переменную;
-  `awk -F*delimeter* '{print $*1/2/3/...*}' *filename*` — позволяет вычленять позиционные переменные, прописанные монолитной строкой, путем указания разделителя после флага `-F`;
-  `awk '{$1/2/3/...="*text*"; print $0}'` — заменит указанную позиционную переменную на новую и выведет обновленный текст;
-  Можно брать команды из файлов. Пример:
	awk_script: `{print $1 " имеет домашнюю директорию по адресу: " $6}`
	`awk -F: -f awk_script passwd` — обработает и выведет содержимое файла `passwd` в формате: `root имеет домашнюю директорию по адресу: /root`, в соответствии с командами из файла `awk_script`. Более script-like альтернатива:
```
	{
	text = " имеет домашнюю директорию по адресу: "
	print $1 text $6
	}
```
-  `awk 'BEGIN {print "*text*"}'` — вывод текста в терминале;
-  Вывод содержимого файла с шаблоном текста `BEGIN` в начале и шаблоном `END` в конце:
```
	awk 'BEGIN {print "*template1*"}
	> {print $0}
	> END {print "*template2*"}' *filename*
```
-  Скрипт для вывода имён пользователей и их домашних директорий из файла `passwd`:
```                                     
	print "Вывод пользователей и их домашних директорий:"
	print "Пользователь\tДом. директория"
	print "-------------\t------------"
	FS=":"
	}
	{
	print $1 "\t\t\t" $6
	}
	END {
	print "-----------------------------------------"
	}
```
    Применяется командой: `awk -f *scriptfile* passwd`;
-  `awk 'BEGIN {FS=":";OFS="-"}{print $1,$6,$7}' passwd` —  выведет 1, 6 и 7 позиционные переменные из файла `passwd`, заменив каждый разделитель `:` на `-`;
-  `gawk FIELDWIDTHS` — разбиение заданной конструкции на позиционные переменные с заданным кол-вом символов в каждой;
-  `ARGC` (*Argument Count*) — числовая переменная, хранящая **количество аргументов** командной строки, переданных `awk` (включая имя самой программы в `ARGV[0]`);
-  `ARGV` (*Argument Vector*) — индексируемый с `0` **массив аргументов** командной строки (`ARGV[0]` — имя интерпретатора, `ARGV[1]`... — имена файлов или присвоения видов `var=val`). Элементы массива можно изменять или удалять (`delete ARGV[i]`) в блоке `BEGIN`, чтобы управлять очередью обработки файлов;
-  `awk ENVIRON` — переменная для вывода заданных переменных окружения. Пример скрипта:
```
	awk '
	BEGIN{
	print ENVIRON["HOME"]
	print ENVIRON["PATH"]
	}'
```
-  `$NF` — указатель на последнюю позиционную переменную;
-  `FNR` — подсчитывает кол-во обработанных записей в файле. При переходе к следующему файлу счётчик сбрасывается;
-  `NR` — подсчитывает кол-во обработанных записей в файле. При переходе к следующему файлу счётчик **не** сбрасывается;
-  `awk '{if ($1 > 20) print $1}' *filename*` — выведет все первые позиционные переменные, значение которых превышает 20. Каждая новая конструкция `if/else' должна заключаться в фигурные скобки;
-  `awk '{ if ($1>20) { x=$1; print x } else { x=$1*100; print x }} *filename*` — скрипт с конструкцией if/else. Условие каждого булева оператора должно быть заключено в фигурные скобки;
-  Скрипт для вычисления среднего значения из файла с тремя строками, состоящими из трёх чисел:
```
	awk '{
	total = 0
	i = 1
	while (i<4)
	{
	total += $i
	i++
	}
	avg=total/3
	print "avg in string: ", avg
	}' *filename*
```
-  Аналог предыдущего скрипта через for:
```
	awk '{
	total = 0
	for (i=1; i<4; i++)
	{
	total += $i
	}
	avg=total/3
	print "avg value in string: ", avg
	}' *filename*
```
-  Экспоненциальное представление числа с помощью `printf`:
```
	awk 'BEGIN {
	x=100*100
	printf "Result: %e\n", x
	}'
```
-  `awk` позволяет использовать математические функции. Примеры:
	-  `awk 'BEGIN{x=sin(3.14); print x}'` — вывод значения синуса числа;
	-  `awk 'BEGIN{x=sin(3.14); print x}'` — вывод значения экспоненциальной функции числа;
-  `awk 'BEGIN{x="*text*"; print toupper(x)}'` — перевод заданного текста в верхний регистр;
-  Скрипт с прописанной функцией для вывода имени пользователя и его домашней директории с последующим её применением на файл `passwd`. В данном случае комбинации `%s` являются заглушками, на место которых по установленному порядку встанут указанные позиционные переменные:
```
	awk '
	function myfunc()
	{printf "User %s has a home directory %s \n", $1, $6
	}
	BEGIN {FS=":"}
	{myfunc()}' passwd
```

#### Регулярные выражения:

-  `awk '/\$/{print $0}' *filename*` — поиск строк с символом, заключенным в `//`. Обязательное экранирование заключенного символа с помощью `\`;
-  `awk '/^*text*/{print $0}' *filename*` — поиск строк с заключенной в `//` конструкцией в начале. Обязательно добавлять символ `^` перед конструкцией;
-  `awk '/*text*$/{print $0}' *filename*` — поиск строк с заключенной в `//` конструкцией в конце. Обязательно добавлять символ `$` после конструкции;
-  `sed -n '/ ^/p' *filename*` или `awk '/\^/{print $0}' *filename*` — поиск строк со спецсимвола через **sed** и **awk**;
-  `awk '!/^$/{print $0}' *filename*` — выводит всё содержимое файла кроме пустых строк за счет символа отрицая `!`;
-  `awk '/Пет./{print $0}' *filename*` — вывод всех строк, содержащих шаблон, где `.` — любой одиночный символ;
-  `awk /д[оир]/{print $0} *filename*` — вывод строк, в которых содержится следующий шаблон: символ `д` в начале и любой символ из выборки, заключенной в `[]`;
-  `awk /Пет[^я]/{print $0} *filename*` — вывод строк, в которых содержится конструкция`Пет` в начале и не содержится любой символ из выборки, заключенной в `[^]`;
-  `awk /сис[а-я]/{print $0} *filename*` — вывод строк, в которых содержится следующий шаблон: конструкция `сис` в начале и любой символ из диапазона от `а` до `я`;
-  `awk '/[0-9][0-9][a-z]/'` — вывод первых трех позиционных переменных, соответствующих шаблону в `//`.  Если хотя бы одна позиционная переменная не соответствует шаблону, вывод не произойдет;
-  `awk '/[[:digit:]][[:digit:]][[:alpha:]]/'` — шаблон из классов спецсимволов. Все классы:
	`[[:alpha:]]` — соответствует любому алфавитному символу, записанному в верхнем или нижнем регистре;
	`[[:alnum:]]` — соответствует любому алфавитно-цифровому символу, а именно — символам в диапазонах 0-9, A-Z, a-z;
	`[[:blank:]]` — соответствует пробелу и знаку табуляции;
	`[[:digit:]]` — любой цифровой символ от 0 до 9;
	`[[:upper:]]` — алфавитные символы в верхнем регистре — A-Z; 
	`[[:lower:]]` — алфавитные символы в нижнем регистре — a-z; 
	`[[:print:]]` — соответствует любому печатаемому символу;
	`[[:punct:]]` — соответствует знакам препинания;
	`[[:space:]]` — пробельные символы, в частности — пробел, знак табуляции, символы NL, FF, VT, CR;
-  `awk '/Пе*/{print $0}' *filename*` — вывод строк, в которых содержится следующий шаблон: конструкция `Пе` и произвольное кол-во символов после нее за счет `*`;
-  `awk '/Пе*т/{print $0}' *filename*` — вывод строк, в которых содержится следующий шаблон: конструкция `Пе*т`. В данном случае `*` означает произвольное кол-во предыдущего символа;
-  `awk '/Петя.*ов/{print $0}' *filename*` — выводит строки, содержащие шаблон: `Петя` в начале, `ов` в конце и произвольное кол-во любых символов между ними;
-  `awk '/Админист?ратор/{print $0}' *filename*` — выбор строк, соответствующих шаблону, при этом содержащие либо **1**, либо **0** символов перед `?`. В нашем случае это буква `т`;
-  `awk '/Админист+ратор/{print $0}' *filename*` — выбор строк, соответствующих шаблону, при этом содержащие **>=1** символов перед `?`. В нашем случае это буква `т`;
-  `awk '/Админист{1/2/3/1,3/...}ратор/{print $0}' *filename*` — выбор строк, соответствующих шаблону, при этом содержащее то кол-во символов, стоящих перед фигурными скобками, которое в них заключено `?`. В нашем случае это буква `т`. Кол-во можно также прописывать через запятую;
-  `awk '/*text1*|*text2*/{print $0}'` — вывод строк, которые содержат хотя бы один из шаблонов;
-  `awk '/сис(админ)?/{print $0}'` — вывод строк, содержащих либо 1, либо 0 конструкций `админ`в указанном месте. В данном случае за счет круглых скобок заключенный в них шаблон воспринимается как один символ;

### Процессы:

`top` — отображает все действующие процессы и загруженность системы в реальном времени;  
`free` — показывает состояние памяти в байтах;  
`free -h` — показывает состояние памяти в Mb, Gb;  
`ps` — показать снимок запущенных из терминала процессов в реальном времени;  
`ps aux` — показывает **полный список всех запущенных в системе процессов** в реальном времени.
- **`a`** — показать процессы **всех пользователей** (а не только ваши собственные).
    
- **`u`** — вывести подробную информацию в **ориентированном на пользователя** формате (показывает имя владельца, загрузку CPU, памяти и т.д.).
    
- **`x`** — показать процессы, **не привязанные к терминалу** (фоновые службы, демоны и системные процессы, которые работают сами по себе);

`dmesg` — просмотр логов ядра системы (часто используется вместе с | grep);  


### Пользователи и группы:

`cat etc/passwd` — отображение всех пользователей системы, их пароля, номера, группы, комментария, домашней директории и shell по умолчанию;  
`sudo cat etc/shadow` — отображение шифров паролей пользователей с метаданными;  
`cat etc/group` — список всех групп;  
su *username* — сменить пользователя;  
`id` — показывает информацию об идентификаторах пользователя и его группах в системах Linux.  

Вот расшифровка вашего вывода:

- **`uid=1000(dufchik)`** — **User ID**. Уникальный числовой идентификатор вашего пользователя (`dufchik`). В большинстве дистрибутивов нумерация обычных пользователей начинается с `1000`.
    
- **`gid=1000(dufchik)`** — **Group ID**. Идентификатор вашей _основной (первичной)_ группы. По умолчанию создается группа с тем же именем, что и у пользователя.
    
- **`groups=...`** — **Дополнительные группы**, в которых состоит ваш пользователь, и их числовые ID. Они определяют ваши права в системе:
    
    - **`sudo` (27)** — дает право выполнять команды с правами суперпользователя (`root`).
        
    - **`adm` (4)** — позволяет читать большинство системных логов (`/var/log`).
        
    - **`lxd` (114)** — дает доступ к управлению контейнерами LXD.
        
    - **`cdrom` (24)**, **`plugdev` (46)** — дают доступ к монтированию и работе с внешними устройствами (CD-ROM, флешки).
        
    - **`users` (100)**, **`dip` (30)**, **`lpadmin` (111)** — стандартные группы для общих пользователей, настройки Dial-Up/VPN и управления принтерами;

`last` — отображает информацию о входах в систему, выходах и перезагрузках;  
`who` — отображение информации о тех кто сейчас вошёл в систему;  
`w` — отображение пользователей вошедших в систему и того что они делают;  
`sudo useradd -m *username*` — добавление нового пользователя (добавлять их может только пользователь, принадлежащий к группе 27(sudo));  
`sudo passwd *username*` — присвоить пользователю пароль;  
`sudo userdel (-r) *username*` — удалить пользователя (флаг -r стирает пользователя вместе с его домашней директорией);  
`sudo groupadd *groupname*` — создать новую группу;  
`sudo groupdel *groupname*` — удалить группу;  
`sudo usermod -aG *groupname* *username*` — добавить пользователя в группу;  
`sudo usermod -aG sudo *username*` — дать пользователю права администратора (команда добавит пользователя в группу 27(sudo));  
`sudo deluser *username* *groupname*` — удалить пользователя из группы;  
`sudo deluser *username* sudo` или `sudo gpasswd -d *username* sudo` — лишить пользователя прав администратора;  
`sudo chown *username* *objname*` — изменить владельца файла или директории;  
`sudo chgrp *groupname* *objname*` — изменить группу файла или директории;  
`sudo chmod *1*+-*2* *objname*`, где `*1*: u/g/o`, `*2*: r/w/x` — добавление или удаление прав владельца/группы/остальных на чтение/запись/исполнение файла или директории. Можно прописывать несколько прав сразу через запятую, например: `sudo chmod g+w, o-r *objname*`. А можно прописать `ugo/a(all)=r/w/x`, что сведёт выбранный параметр к одному значению во всех полях. Также можно прописывать права с помощью цифр для каждого поля отдельно, к примеру, комбинация 777 в `sudo chmod 777 *objname*` даст права rwx всем полям. Работает как двоичный код:
- `--- — 0`;
- `--x — 1`;
- `-w- — 2`;
- `-wx — 3`;
- `r-- — 4`;
- `r-x — 5`;
- `rw- — 6`;
- `rwx — 7`.
Ещё один важный момент. Для защиты объектов в директории от случайного удаления может понадобиться **sticky bit**. Он отображается как флаг `t` в конце кода с правами директории. Всё дело в том что даже если право на изменение (w) объекта будет, скажем, только у владельца, то все остальные всё равно смогут его стереть, если в директории в которой объект расположен не будет стоять флаг `t`, даже несмотря на отсутствие у них соответствующего права в коде этого объекта. Поставить или убрать этот флаг можно следующими командами:
`sudo chmod o+-t *dirname*` или `sudo chmod [0-1][0-7][0-7][0-7] *dirname*`

### Сети:

`ping *address*`  — считывание пинга сервера по указанному адресу (Ctrl + C — прервать запись, Ctrl + Z — остановить вывод пинга в терминал (запись продолжится в фоновом режиме) (команда fg — возобновить вывод));  
`ifconfig` — отображает и настраивает сетевые интерфейсы, а также их IP-адреса и параметры сетевой карты;  
`ip addr show` — современный аналог `ifconfig`, выводящий полную информацию о сетевых интерфейсах и их IPv4/IPv6 адресах;  
`route` — показывает и позволяет редактировать системную таблицу маршрутизации IP-пакетов;  
`host` — выполняет простые DNS-запросы для быстрого преобразования доменных имён в IP-адреса и наоборот;  
`dig` — утилита для получения подробных данных из DNS-серверов с детализацией записей всех типов;  
`netstat` — выводит активные сетевые подключения, открытые порты, статистику интерфейсов и таблицу маршрутизации;

`$0` равен `./*scriptname*.sh`;

 `read -p "*comment*" *varname*` — сохранить ввод пользователя в переменную;
